# factory-test-ios

A small, deliberately clean SwiftUI iOS app that the [Security Software Factory](https://github.com/AakashDadhich/security-factory) runs against. It should pass every security stage.

- The Xcode project is generated by XcodeGen from `project.yml` and is not committed.
- One Swift Package dependency, `apple/swift-log`, pinned exactly in `project.yml` and `Package.resolved`.
- App Transport Security is left at its defaults. A sample value is stored in the Keychain with `kSecAttrAccessibleWhenUnlockedThisDeviceOnly`. A privacy manifest (`Sources/PrivacyInfo.xcprivacy`) declares no tracking and no collected data.
- The factory builds an unsigned device `.ipa` on a `macos-15` runner and scans it with MobSF on Linux.
